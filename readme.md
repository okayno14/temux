# Intro

Temux - simple escript script for templating tmux sessions.

# Installation

Temux - plain text single file written in erlang.

Installation:

* Just download the file and put to `~/.local/bin`

Tested on otp 24.

# Usage

```
temux help - all available options
temux help config - example of config file
```

By default it reads `./tmux_sessions` file.

To create sessions:

```
temux
```
